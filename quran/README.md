# خطوط المصحف (QCF V2، ٦٠٤ صفحة)

`v2/pNNN.woff`: خط لكل صفحة من مصحف المدينة النبوية (١٤٢١هـ، ١٥ سطر). «يومي» (1.26+) ينزّلها أول ما تفتح «القرآن الكريم» من Quran Foundation، وهذي نسخة احتياط إذا ما وصلها:
الصفحة الحالية وعشر حواليها، وبعدين الباقي على الواي فاي، وتنحفظ بملفات التطبيق وتشتغل بدون نت.
